# Datacircle

Find the best GTM APIs

We benchmark all the GTM APIs and we put the results on our website, [datacircle.dev](https://datacircle.dev).

Our MCP server is open to anyone, with no key: api.datacircle.dev/mcp. It has two tools, `list_apis` and `search_plans`. The plugin adds the server and our skill.

Our API is open too: https://api.datacircle.dev/v1 (spec: https://api.datacircle.dev/v1/openapi.json).
